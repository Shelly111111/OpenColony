📌 配置存储说明

            
    
              
  • 大模型配置: <项目根>/.env（ANTHROPIC_API_KEY / ANTHROPIC_BASE_URL / ANTHROPIC_MODEL）
    • 
              
  • 模板文件: <项目根>/.env.example（.env 不存在时回退）
    • 
              
  • 其他配置: ~/.opencolony/config.json（claude_path / claude_url / max_agents / run_mode）
    • 
              
  • 任务日志路径: <项目根>/worker-logs/<traceId>_<timestamp>/
    • 
              
  • 通信数据库: ~/.opencolony/messages.db（SQLite + WAL模式）
    • 
              
  • 角色配置: scheduler/config/role.json
    • 
              
  • 技能配置: scheduler/config/skill.json
